How This Works

This page demonstrates Kamal Proxy's ForwardAuth integration:

  1. Your request arrived at Kamal Proxy
  2. Kamal Proxy sent a subrequest to Authelia for authentication
  3. Authelia verified your session cookie
  4. Authelia returned 200 OK with user headers
  5. Kamal Proxy copied the headers and forwarded your request here

Features Demonstrated

  • Forward Authentication middleware
  • Authelia integration
  • Session-based authentication
  • Automatic redirect to login on unauthorized access
  • Header forwarding from auth service
  • Zero-downtime deployment capability

Test Configuration

This service was deployed with:

kamal-proxy deploy app \
  --target test-app:80 \
  --host app.localhost \
  --forward-auth-url http://authelia:9091/api/authz/forward-auth
